# Маршрутки ПМР

Простой справочник маршрутов общественного транспорта Приднестровья.

Сейчас это прототип. Первая версия содержит несколько маршрутов Тирасполя и позволяет посмотреть основную информацию о них.

## Возможности

- поиск маршрута по номеру или названию;
- стоимость проезда;
- первый и последний рейс;
- интервал движения;
- маршрут туда и обратно;
- основные улицы и особенности маршрута.

## Технологии

- React;
- TypeScript;
- Vite;
- CSS Modules.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

Проект находится на стадии прототипа. Данные о маршрутах могут быть неполными или неточными.
